# Orange Video Cover Brand Profile

## Identity

- Creator: Orange
- Main topics: 编程、全栈开发、软件工程
- Primary audience: 有一定经验的开发者、AI Coding 从业者
- Secondary audience: 泛技术观众、求职者和学生
- Primary platform: Bilibili
- Desired feel: 可爱、活泼、偏二次元，但保持技术内容的专业度
- Profile status: 初版，后续根据实际封面迭代

## Brand Anchors

- Primary logo: `skills/orange-video-cover/assets/fixed/icon.png`
- Logo meaning: 橙子与香蕉组合，配绿色叶片
- Logo role: 固定角标，不作为每张封面的主要内容主体
- Logo placement: 右上角
- Logo size: 画布宽度约 6%–10%
- Title area: 左侧中上区域
- Subject area: 右侧或中央，根据内容构图调整
- Border or frame: 不固定
- Recurring symbol: 水果 Logo；可使用简单表情和装饰符号
- Fixed text ID: 暂不使用

## Typography

- Primary font direction: 粗圆体，优先选择免费商用或系统可用字体
- Secondary font direction: 像素字体，仅用于期号、标签或装饰
- Text casing: 根据中文或英文内容自然选择
- Readability: 标题必须在 Bilibili 缩略图尺寸下清晰可读

## Color System

- Primary accent: Orange
- Secondary accent: Banana Yellow
- Supporting accent: Leaf Green
- Default background: Deep Charcoal
- Alternate background: Cream
- Contrast rule: 深色背景使用浅色标题，浅色背景使用深色标题；橙色用于强调而不是铺满整张画面

## Layout Rules

- Default format: Bilibili 16:9 横版
- Default composition: 左侧短标题，右侧技术主体，右上角固定 Logo
- Information ratio: 约 70% 内容表达，约 30% 品牌个性
- Focal point: 一个主要视觉焦点
- Safe area: 标题与 Logo 保持在平台安全区内
- Density: 中低信息密度，避免小字、完整代码和完整架构图

## Style Direction

- Supported styles: Editorial Poster、Dark Technical Split、Human-Centered Tech、Minimal Concept
- Style selection: 根据视频内容选择，保持 Logo、色板和字体一致
- Default preference: Dark Technical Split
- Anime elements: 少量使用；优先使用现有水果 Logo、简单表情和装饰符号
- Texture: 按 Style Recipe 选择，不作为固定元素

## Content Rules

- Main expression: 教程/实战与软件工程观点、经验
- Secondary expression: 工具和技术测评、项目复盘、求职与成长
- Cover principle: 一张封面只表达一个核心技术概念
- Technical visual language: 使用简化的模块、工作流、工具、断点、管道或其他视觉隐喻
- Logo usage: 品牌个性服务于内容表达，不取代技术主题

## Asset Rules

- Fixed assets: Logo、未来确认的固定字体或固定符号
- Optional assets: 纹理、贴纸、背景、装饰图标
- Reference assets: 其他创作者封面和风格参考，仅用于分析

## Anti-patterns

- 让水果 Logo 或可爱元素抢走技术主题
- 每张封面使用完全不同的品牌色、字体或 Logo 位置
- 使用大量小字、完整代码或完整架构图
- 使用与视频内容无关的科技装饰
- 复制其他创作者的完整封面体系
- 未确认就把临时偏好写入本档案
