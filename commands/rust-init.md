# Rust Init

Use this command as the Claude Code manual entry point for Rust project workflow initialization or retrofit.

Follow `skills/rust-workflow/SKILL.md` completely. That skill owns the detection checklist, setup flow, template choices, preservation rules, verification, and final report format.

Codex users should invoke `$rust-workflow` directly.
