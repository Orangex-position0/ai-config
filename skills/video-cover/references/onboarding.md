# Onboarding

Use onboarding only when the user has no usable `.video-cover/brand-profile.md`, asks to create a cover system, or wants to update recurring cover style.

## Minimal Questions

Ask only the missing questions needed to create a usable first profile:

1. What is the channel, account, or creator name?
2. What technical fields does the channel mainly cover?
3. What should the covers feel like: professional, sharp, calm, playful, experimental, engineering-heavy, or another direction?
4. What fixed identity assets exist: logo, avatar, ID text, slogan, recurring symbol, or none yet?
5. What colors are preferred or forbidden?
6. Should covers use real people, illustration, 3D, screenshots, abstract diagrams, or minimal typography?
7. Which platforms matter most?

Stop once the answers are enough to draft a profile. Do not turn onboarding into full brand consulting.

## Drafting Rules

Prefer free commercial fonts or widely available system fonts unless the user provides licensed fonts.

Write concrete visual anchors, not abstract taste words. Replace "clean and techy" with rules such as "large left-aligned title, thin outline frame, one high-contrast accent, simplified vector metaphor."

Keep the first profile small. Mark uncertain choices as `provisional` so later covers can refine them.
