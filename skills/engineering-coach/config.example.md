# Engineering Coach Config

Local configuration for the `engineering-coach` skill.

## Fields

- `profile_path`: Markdown file for the long-term learning profile.
- `practice_records_dir`: directory for one practice record per exercise.
- `practice_record_prefix`: filename prefix for new practice records.
- `default_write_policy`: `ask`, `write`, or `no-write`.
- `default_teaching_mode`: `light`, `standard`, or `intensive`.
- `locale`: preferred output locale. Use `zh-CN` for Chinese templates and English locales such as `en-US` for `templates/*.en.md`.
- `schema_version`: config schema version.
