## Transferable rules

- Keep one dominant focal point and one core concept.
- Borrow hierarchy, contrast, spacing, and metaphor logic—not exact layouts, text, silhouettes, or logo combinations.
- Replace placeholder text and identity marks before delivery.
- Use the fixed personal mark from `assets/fixed/icon.png` as the brand anchor; do not copy a reference image's `LOGO` block.
- Treat generated text, decorative code, and technical labels as supporting elements that must remain sparse and readable.
