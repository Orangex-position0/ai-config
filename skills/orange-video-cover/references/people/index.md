# People Reference Index

These images are pose references, not a requirement to use a person. Preserve the creator's real identity when using them; do not turn a pose into a recurring fictional character.

| Asset | Pose cue | Good fit | Composition guidance |
| --- | --- | --- | --- |
| `posture-1.png` | Thumb up, direct front-facing approval | Recommendation, result, validated practice | Place on the right when the title or proof sits left. |
| `posture-2.png` | Smile with raised fingers | Lists, choices, multi-step tips, upbeat tutorials | Leave hand clearance; use as a lively secondary focal point. |
| `posture-3.png` | Side profile looking upward | Vision, architecture, future-facing ideas | Reserve the gaze direction for the title or main metaphor. |
| `posture-4.png` | Pointing sideways with both hands | Comparison, callout, before/after, explanation | Place the pointed direction toward the key object or title. |
| `posture-5.png` | Holding an invisible object | Product feature, concept, AI tool, abstract mechanism | Use the hand space for one compact symbol or UI fragment. |
| `posture-6.png` | Neutral front-facing portrait | Technical tutorial, identity-led series, default fallback | Use when the topic needs credibility without a strong emotion. |
| `posture-7.png` | Open-handed shrug | Trade-offs, uncertainty, debugging, common mistakes | Pair with a clear problem metaphor; do not use for a confident result claim. |
| `posture-8.png` | Close smiling portrait | Opinion, announcement, experience, personality-led content | Keep the face large and the title short. |
| `posture-9.png` | Holding an invisible object, wider framing | Concept explanation, tool workflow, vertical adaptation | Prefer when more room is needed around the hands or torso. |

## Selection rules

1. Choose a pose only after the content type and focal metaphor are fixed.
2. Use one person pose at most; do not combine several poses in one cover.
3. If the topic is abstract or technical-first, prefer `posture-6.png` or no person.
4. If the pose conflicts with the title direction, crop or mirror only when the result remains natural.
5. Treat the white outline as a removable reference treatment; match it to the selected Style Recipe rather than copying it blindly.
