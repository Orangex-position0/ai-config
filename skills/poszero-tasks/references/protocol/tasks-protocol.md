# Tasks Protocol

- For `change.md` or an existing Approved Ready task, return its execution scope without creating `tasks.md`.
- For an Approved Plan, create minimal ordered, verifiable tasks with `REQ-*` coverage, relevant `SC-*` links, dependency checks, and verification commands. Use functional batches or vertical slices when they clarify execution.
- Generate an Execution Packet for Implement. Keep it scoped to the current batch or slice.
